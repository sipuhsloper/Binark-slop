# Binark — финальный отчёт

Приложение **Binark** (`com.binark.Binark`, версия `1.0.0`) — нативный
конвертер текста, целых чисел и файлов в бинарное представление и обратно,
реализованный на C17 + GTK 4 + libadwaita.

## Ключевые возможности

- **Текст:** кодирование UTF-8 → биты (с разделителями, переносом строк,
  настройкой байт на строку, точное сохранение байтов), декодирование обратно;
  строгие ошибки (неполный байт, недопустимый символ, невалидный UTF-8, NUL);
  русский язык и эмодзи.
- **Числа:** основания 2–12, 16, 32 и 64 (цифры 0–9, A–Z, a–z, для 64 ещё + и /),
  знаки, ноль, произвольная точность, префиксы `0b/0o/0x` с проверкой, регистр букв.
- **Файлы:** потоковое преобразование, прогресс, отмена, проверка свободного места,
  временный файл + атомарный `rename`, сохранение при ошибках, компактный формат.
- **UI:** GTK 4 + libadwaita, русский язык, адаптивная компоновка, темы,
  поиск, история, настройки, диалоги, уведомления, доступные подписи, горячие клавиши
  `Ctrl+Enter`, `Ctrl+C`, `Ctrl+V`, `Ctrl+L`, `Ctrl+O`, `Ctrl+Shift+S`, `Ctrl+,`.

## Исправления в этой сессии

1. **Критический:** `on_text_convert_clicked` и `on_text_paste_clicked` были
   подключены через `g_signal_connect_swapped`, хотя принимают два аргумента
   (`GtkButton`, `user_data`). Из-за этого `user_data` содержал неверный указатель,
   что приводило к segfault в `gtk_text_view_get_buffer` при любом запуске
   преобразования. Исправлено на `g_signal_connect`.
2. Кнопки с иконками показывали только иконку (label заменялся `gtk_button_set_icon_name`)
   — исправлено на контейнер иконка+текст с доступной подписью.
3. Принимается символ минуса U+2212 (типографский) для чисел.
4. `g_file_set_contents_full` теперь пишет историю атомарно.
5. Модификация файлов save-результата уважает umask.

## Проверка запуска и GUI

- После исправления segfault приложение запускается без падений, корректно
  завершает работу.
- Через AT-SPI (GNOME Accessibility) проверены: конвертация текста (кодирование,
  декодирование, ошибки, статистика), числа (основания, знаки, большие числа,
  префиксы, ошибки), вкладки, поиск, диалоги настроек/«О программе»/история,
  темы (через `GSettings` и обновление меню).
- End-to-end файл: выбор файла, сохранение результата, преобразование через
  `Ctrl+O` + `Ctrl+Shift+S` + `Ctrl+Enter` — выходной файл совпал с ожидаемым
  битовым представлением.
- `GSETTINGS_SCHEMA_DIR=build/gschemas` обязателен для запуска собранного бинарника.

## Ограничения

- Дробные числа не поддерживаются (целые только).
- Большие целые обрабатываются алгоритмом повторного деления (O(n²) в цифрах).
- Текстовый режим не допускает нулевых байтов.
- `GSettings` применяет тему для процесса приложения.
- В тестовой среде отдельные проверки GTK-file-chooser через AT-SPI требуют
  сторонних инструментов; стандартные пути (XTest + команды) используются для
  end-to-end проверок.
